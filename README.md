# WAM+3D Research Map

WAM+3D 项目的静态研究地图。首页默认展示 2026-10-30 文献研读后提出的新路线；旧实验和上一版计划作为历史记录保留。

## 查看页面

直接用浏览器打开 `index.html`，或在当前目录启动任意静态文件服务器。

页面顶部可以在两个视图之间切换：

- **当前路线**：六项近期工作的机制、证据、真正启发与不能照搬之处；对照直接 3D 动作策略（路径 A）与显式状态＋空间代理视频（路径 B）。这里是待消融的研究问题，不把“预测后果＋重排动作”预先认定为新方法或成果。
- **历史实验**：此前静态 3D 注入视频隐藏层的实现、结果、数据问题和旧计划；其中“当前”等表述是 2026-10-28 的历史快照，不代表现在的执行方向。

整个站点为单文件静态页面，不需要安装依赖或执行构建。
