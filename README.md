# WAM+3D Research Map

WAM+3D 项目的静态研究地图。首页默认展示 2026-10-31 的新立题草案；旧实验和此前构想作为历史记录保留。

## 查看页面

直接用浏览器打开 `index.html`，或在当前目录启动任意静态文件服务器。

页面顶部可以在两个视图之间切换：

- **当前路线**：以可执行控制指令为输入，研究机器人实际运动、接触和物体变化的联合三维推演，再检验同一预测状态能否约束视频和改善动作。页面逐项标明相近论文已做的工作、候选缺口与待验证实验；新颖性和效果尚未证实。2026-10-30 的两路径构想已折叠为历史讨论。
- **历史实验**：此前静态 3D 注入视频隐藏层的实现、结果、数据问题和旧计划；其中“当前”等表述是 2026-10-28 的历史快照，不代表现在的执行方向。

整个站点为单文件静态页面，不需要安装依赖或执行构建。
