# WAM+3D Research Map

WAM+3D 项目的静态研究地图。首页默认展示 2026-10-31 重构后的形状先验研究路线；此前的接触动力学构想及实验作为独立视图保留。

## 查看页面

直接用浏览器打开 `index.html`，或在当前目录启动任意静态文件服务器。

页面顶部可以在三个视图之间切换：

- **形状先验新路线**：回到最初“已知物体库中的完整形状如何帮助 WAM”的问题，聚焦当前观察缺失关键几何、但执行前可可靠检索形状的情形。页面对照原规划、旧 P2 和近期论文，给出分阶段研究方法、强基线与停止条件；新颖性和效果尚未证实。
- **动力学备选**：2026-10-31 的另一立题草案，以可执行控制指令为输入，研究机器人实际运动、接触和物体变化的联合三维推演。它可作为形状先验路线的下游组件或强基线，但不是同一个研究问题；2026-10-30 的两路径构想已折叠在此视图的历史讨论中。
- **历史实验**：此前静态 3D 注入视频隐藏层的实现、结果、数据问题和旧计划；其中“当前”等表述是 2026-10-28 的历史快照，不代表现在的执行方向。

整个站点为单文件静态页面，不需要安装依赖或执行构建。
